# Portfolio Professionale – UX/UI Design
### Candidato: Imma Carano

Questo repository contiene il codice sorgente del mio portfolio personale, progettato e sviluppato per presentare i miei progetti di UX Research, UI Design e Accessibilità digitale.

---

## 🎯 Obiettivi del Progetto
Il sito è stato costruito con un approccio **User-Centered**, focalizzandosi su:
* **Minimalismo ed Eleganza:** Un design pulito che non distragga dai contenuti.
* **Accessibilità:** Rispetto dei contrasti cromatici e struttura semantica corretta per screen reader.
* **Responsiveness:** Navigazione fluida su desktop, tablet e smartphone.

---

## 📁 Struttura della Repository
Seguendo le best practice di sviluppo, il progetto è organizzato in modo modulare:

* `index.html` — Pagina principale (Home & Portfolio).
* `cv.html` — Pagina dedicata al curriculum professionale.
* `assets/` — Cartella contenente tutte le risorse statiche:
    * `css/` — Fogli di stile (style.css).
    * `img/` — Asset grafici, icone e fotografie.
    * `pdf/` — Case studies, documentazione e CV scaricabile.

---

## 🛠 Tecnologie Utilizzate
* **HTML5**: Struttura semantica per una migliore SEO e accessibilità.
* **CSS3**: Custom properties (variabili), Flexbox e CSS Grid per il layout.
* **Bootstrap 5**: Utilizzato per la griglia responsive e componenti base.
* **JavaScript**: Implementazione di *Intersection Observer API* per le animazioni al caricamento e gestione del menu mobile.
* **EmailJS**: Integrazione per l'invio diretto di email tramite il form di contatto senza backend dedicato.
